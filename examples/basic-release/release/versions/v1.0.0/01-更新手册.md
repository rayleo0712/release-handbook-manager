## 6. 发布执行步骤

1. 核对 `release/version.json` 中的版本号。
2. 执行发布前检查。
3. 按顺序执行 `02-db-xxx` 数据库脚本。
4. 按顺序执行 `03-config-xxx` 配置脚本。
5. 部署应用程序。
6. 执行人工操作事项。
7. 完成发布后验证。
8. 记录发布结果。

## 7. 回滚方案

- 回滚触发条件：初始化结构或发布材料存在明显错误。
- 数据回滚方式：当前示例未涉及数据库变更。
- 配置回滚方式：删除新增模板并恢复旧结构。
- 程序回滚方式：当前示例未涉及业务逻辑变更。
- 回滚注意事项：真实项目中应结合发布环境补充具体说明。
