# 测试覆盖规则（rta 分片）

> 本分片由 `skills/release-test-auto/SKILL.md` §1.2.1 逆向场景补齐辅助真源、§四 测试覆盖规则搬迁而来，原文口径不变。
> 加载时机：判断逆向场景是否可自动补齐、设计正向/逆向用例、核对覆盖是否充足、确定测试执行形态（快速/渲染）与门控、判断 SQL 造数边界时。

## 1.2.1 逆向场景补齐辅助真源

当 `05-1` 中逆向场景不足、需要由 AI 自动补齐时，可读取以下辅助真源：

- 当前版本 `01-更新手册.md`
- 当前版本 `04-发布检查清单.md`
- 项目中的菜单 / 路由 / 权限配置
- 项目中的接口文档、状态流转说明、角色权限说明

约束：

1. 只有在上述辅助真源至少存在一类、且足以支撑页面 / 状态 / 权限判断时，才允许自动补齐逆向场景
2. 若缺少这些辅助真源，本 Skill 应明确提示“逆向测试真源不足”，不得凭空脑补逆向场景
3. 自动补齐的逆向场景必须在结果报告中单独标记为“AI 自动补充逆向场景”
4. 自动补齐的逆向场景必须生成稳定的 `case_id`，并纳入 `test-output/case-results/*`、`total_count`、`completed_count`、`checkpoints.json` 与最终报告统计；不得只在文字说明中提及而不进入统一计数

## 四、测试覆盖规则

自动化测试**不得只覆盖正向场景**。

### 4.1 正向场景

- 主流程可顺利执行
- 多角色审批链可走通
- 列表查询、分页、详情展示正常

### 4.2 逆向场景

至少补齐以下三类：

1. **权限逆向**
   - 无权限账号访问页面
   - 无权限账号直接打开 URL
   - 非当前审批人尝试审批

2. **状态逆向**
   - 非法状态下重复提交
   - 已终止对象尝试恢复
   - 已处理记录再次操作

3. **输入逆向**
   - 必填项为空
   - 超长输入
   - 非法格式
   - 边界值输入

### 4.3 规则

- 若 `05-1` 已明确写出逆向场景，则严格按 `05-1` 执行
- 若 `05-1` 主要只有正向场景，且 `01` / `04` / 菜单路由权限配置 / 接口文档等辅助真源充足，本 Skill 才可基于页面、状态、权限补齐必要逆向测试
- 若辅助真源不足，应明确提示"逆向测试真源不足"，不得凭空补齐
- 自动补齐的逆向测试必须在结果报告中单独标明"AI 自动补充逆向场景"

## 五、测试类型与执行门控（全局适用）

同一套 `05-1` 用例**不区分类型**——类型属于**执行阶段**属性：全量用例先以快速形态执行，通过后再以渲染形态执行。

### 5.1 两类测试形态

| 形态 | 工具 | 账号 | 断言目标 |
|---|---|---|---|
| 类型一·快速测试 | curl / API 层脚本 | 按操作角色用对应账号的 token 发请求 | 接口返回结果 + 后端真实状态（数据落库、状态字段变化、任务生成），不得只看 HTTP 200 |
| 类型二·渲染测试 | Playwright 浏览器渲染 | 对应账号登录页面，1:1 真实操作流程 | 前端权限显隐（按钮/菜单）、页面渲染正确性、交互请求成功 |

- 账号来源：当前版本 `05-1 §2 角色准备`（含「节点/角色 → 测试账号」映射，规范见 rhm `templates-05-1-功能验收用例.md`）
- 两形态用例集合一致：渲染测试不是抽样，是同一批用例换执行形态

### 5.2 执行门控（强制）

1. 默认只执行类型一（快速测试），覆盖全量用例
2. 类型一存在失败 → **停止，不得进入渲染测试**；修复后重跑类型一
3. 类型一全部通过，或用户明确指令要求渲染测试 → 才执行类型二
4. 用户明确指令可直接跳过门控进入类型二（如发版前验证、前端问题专项）
5. 两阶段结果分别落盘并标注阶段（`run-status.json` 增 `stage: "quick" | "render"`），最终报告分阶段统计；渲染测试未执行时必须注明原因（快速未全过 / 无明确指令）

## 六、流程引擎专项约束（被测系统含流程引擎时附加）

- **SQL 边界**：仅允许非流程基础数据造数（用户/角色/字典/菜单授权/非流程业务数据）与测试中临时修复、回滚（须按 order 分片回写规则留痕）
- **禁止 SQL 直推流程**：流程实例的创建、推进、回退、跳转一律经真实引擎/API 完成，不得改状态表快进——**含测试夹具**：需要「在途流程到第 N 节点」等前置状态时，必须 API 逐节点推进产生（顺带验证前序节点），禁止 SQL 改字段直达
- 快速测试须断言引擎真实状态：下一节点任务已生成、流程状态字段已变化、历史记录一致
