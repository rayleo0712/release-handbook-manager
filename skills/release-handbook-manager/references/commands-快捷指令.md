# 快捷指令表（rhm 前缀，16 条）

> 加载时机：用户输入 `rhm` 开头快捷指令（如 `rhm发布准备`）、或问「rhm 有哪些快捷指令」时
> 定位：指令 = 确定性入口，只路由到既有分片组合，**不发明新流程、不复述规则细节**（真源仍在各分片）；与自然语言触发共存——用户不用指令说「准备发版」也按索引表正常路由
> 前置纪律：任何指令执行前先做 `redlines` 四段判断（版本号/目录一致性）；写操作指令无一豁免

## 1. 指令总表

| 指令 | 一句话动作 | 路由分片 |

| rhm刷新脚本 | 强制重生成 >50KB 真源驱动脚本 | sourcegen §2 |
| rhm人工操作 | 登记 1 条人工操作到 01 §5（8 类校验） | scripts-sql §4.2 |
| rhm插队 | NNN 插队整体重编号 | scripts-sql §4.4.2 |
| rhm状态 | 只读体检：版本/未物化/待刷新/脚本清单/材料缺项 | —（纯只读） |

## 2. 动作分解（每条指令的执行序列）

### 开发期

- **rhm登记**（最高频）：① redlines 四段判断 → ② 07 追加一行（flow §2：6 类选 1、CHG 沿用或新开）→ ③ 判断是否需 02/03：需则按 §4.3 归并扫描后追加片段/新建 → ④ 真源驱动 >50KB 只标 `01 §4.1/§4.3` 真源状态=待刷新 → ⑤ 台账/05-1/06 **不动**（物化视图）
- **rhm生成脚本**：① §4.3 扫描已有脚本并报告证据（「已有 XX 覆盖表 YY」）→ ② 同单元追加片段、否则新建（最大号+1）→ ③ 头部四字段 + 尾部校验区 + 多片段分段校验（§4.1）→ ④ 同步 01 §4.1/§4.3 表行 → ⑤ 建议 `-ListOnly`
- **rhm刷新脚本**：① sourcegen §2：比对挂起期间追加的片段，未被真源覆盖的并入 → ② 以最新真源重生成（头尾校验齐全）→ ③ 真源状态=已同步 → ④ `-ListOnly` 0 违例
- **rhm人工操作**：① §4.2 的 8 类清单判定：在范围内 → 落 01 §5（入口/顺序/内容/预期/校验五要素齐全）；超范围 → 提示「应脚本化」并拒绝登记
- **rhm插队**：① 报告插队影响面（受影响脚本列表）→ ② §4.4.2 从大号到小号整体重编号 → ③ 文件名 + `-- @depends` + 01 §4.1/§4.3 表 + 04 §8 命令同步改 → ④ `-ListOnly` 0 违例后反馈新对照表
- **rhm状态**：只读输出 5 项——① version.json 版本号+status ② 07 流水最大条号 vs 物化锚点差值（未物化条数）③ 真源状态=待刷新计数 ④ 02/03 脚本清单（NNN 升序）⑤ 8 类材料缺项清单；**不写任何文件**

### 物化与测试

- **rhm物化05-1**：① flow §3 触发点 1 成立 → ② 从流水聚合（新增功能/调整→功能用例、缺陷→回归用例；验收要点→预期骨架；页面路径查代码补全）→ ③ 10 列结构 + 账号迁移（templates-05-1 §6.3.1）→ ④ 更新 07 锚点行
- **rhm物化台账**：① flow §4 按 CHG 聚合（首条流水=原始需求、末条=当前有效、中间=本轮调整）→ ② §A.2 块格式写入 01 §3 → ③ 旧块仅状态变化才更新 → ④ 更新锚点
- **rhm测试**：① 前置条件分片 6 项检查（启动命令/数据基线/账号/用例覆盖/归档/两类型）→ ② 05-1 未物化或落后 → 先执行 rhm物化05-1 → ③ 齐全后明确移交 `release-test-auto`（两类型门控：默认 quick 全量，过或指令才 render）

### 发布期

- **rhm发布准备**（终稿指令，顺序固定）：① 全部物化：台账 + 05-1 + 06（flow §3 触发点 3）→ ② 待刷新清零：重生成全部真源状态=待刷新脚本（sourcegen §2 纪律）→ ③ 04/05-1/06 终稿核验（计数命令、签字区占位）→ ④ 巡检 11 项（inspect），任何一票否决项不过即停并报告
- **rhm巡检**：直接 inspect 11 项；**不物化、不刷新**——材料已是终态、只要体检时用
- **rhm预检**：① 确认版本目录 `run-release.ps1` 存在（缺失则按 runner 分片复制资产）→ ② `-ListOnly` 执行并报告违例清单（0 违例才放行）
- **rhm补跑**：① 读最近 run-report 的 FAIL 区间 → ② 按预检打印的执行计划换算 `-StartIndex/-EndIndex` → ③ 执行并确认全部 PASS → ④ 结果登记 04 §8.5
- **rhm归档**：① 05-发布后验证记录.md → `archive/05-验证记录-第N轮.md`（N 续号）→ ② run-report 产物在 05 中登记归档路径 → ③ 归档后 05 保留骨架（templates-05 瘦身规则）

### 版本管理

- **rhm初始化**：init 分片全流程（version.json 占位号 + 项目规则 + 版本目录 + 8 类骨架 + runner 复制）；版本号无人工指令用 vX.Y.Z 占位
- **rhm切版本**：redlines 强制前置 → switch 10 步；跨版本延续候选必须列表等人工选，禁止替用户选
