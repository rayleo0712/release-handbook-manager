## 一、变更背景

项目实际使用中暴露两类真实问题，驱动本轮治理：

1. **SQL 执行顺序与命名不一致导致更新出错**：前置依赖只写在注释里，文件名序号与实际先后脱节
2. **版本目录混入 skip 类脚本**：黑名单跳过、无校验区、测试库专用三类脚本混入发布包，执行无反馈、真假难辨
3. **rta 测试质量问题**：SQL 直推流程绕过引擎副作用，测不出真实流转；前端权限与渲染无覆盖

## 二、rhm（release-handbook-manager）侧变更

### 2.1 run-release.ps1 批量执行器（新增资产，每版本一个）

- 版本无关设计：自动取所在目录名为版本号，从 `skills/release-handbook-manager/assets/` 原样复制，禁止逐行生成
- 获取三级策略：本地资产复制（默认）/ GitHub raw 下载最新版 / 提示人工下载；资产只复制不读入上下文（省 token）
- **执行顺序硬预检**（§4.4，违例 exit 2、一条 SQL 都不执行）：命名三位定宽、同前缀序号唯一、`-- @depends` 依赖存在且排序位严格更小
- **单一通道**（§4.5）：废除黑名单 skip 机制；缺校验区 / 含 `@test-only` / 000 占位含语句均预检拦截；执行结果只有 PASS/FAIL，解析不出反馈按 FAIL（fail-closed）
- 新参数：`-ListOnly`（只预检+打印执行计划，不连库，巡检/CI 用）、`-StopOnError`（失败即停保护依赖链）、`-StartIndex/-EndIndex`（区间补跑）
- 退出码：预检违例 exit 2、存在失败 exit 1，可供 CI 直接卡门禁

### 2.2 scripts-sql-规范 新增三节

- **§4.3 归并优先**：同功能单元变更必须追加片段到已有脚本（02 与 03 不互并），不得一条变更建一个文件
- **§4.4 文件名即执行序**：命名文法 `前缀-NNN-简述.sql`（NNN 三位定宽、同前缀唯一）；跨文件依赖必须写 `-- @depends` 机器声明；插队须整体重编号（从大号往小改）
- **§4.5 单一通道**：版本目录只放生产必执行脚本；备份等运维登记人工操作、测试造数归 `scripts/test-auto/`

### 2.3 其他

- SKILL.md description 改为触发式写法（"Use when..."），目录树与索引表同步
- init/switch/workflow/inspect/templates-01/04 等分片联动更新
- assets 资产编码要求：UTF-8 带 BOM（PS 5.1 GBK 代码页必需）

## 三、rta（release-test-auto）侧变更

### 3.1 两类型测试与执行门控（全局适用）

| 形态 | 工具 | 账号 | 断言目标 |
|---|---|---|---|
| 类型一·快速测试 | curl / API 层 | 按操作角色用对应账号 token | 接口结果 + 后端真实状态，不得只看 HTTP 200 |
| 类型二·渲染测试 | Playwright | 对应账号登录页面，1:1 真实操作 | 前端权限显隐、渲染正确性、交互请求成功 |

**门控规则**：默认全量跑快速测试；存在失败 → 停止修复重跑，不得进入渲染；全部通过或用户明确指令 → 才执行渲染测试。

### 3.2 流程引擎专项约束（coverage §6）

- SQL 仅允许非流程基础数据造数 + 测试中临时修复/回滚（留痕回写）
- **禁止 SQL 直推流程（含测试夹具）**：在途前置状态必须 API 逐节点推进产生
- 快速测试须断言引擎真实状态（下节点任务已生成、状态字段已变化）

### 3.3 联动改动

- `run-status.json` 新增 `stage: quick|render` 字段；断点恢复先判阶段；完成判定补阶段口径
- 执行顺序升级为 16 步（第 13 步为门控判断点）
- 生成脚本分两阶段形态（`run-uat-quick` / `run-uat-render` 或单脚本 `-Stage`）
- rhm `templates-05-1` 角色准备补「流程节点 → 操作角色 → 测试账号」映射要求；`templates-自动化测试前置条件` 补两类型联动说明

## 四、兼容性影响（使用者必读）

| 变化点 | 影响 | 迁移动作 |
|---|---|---|
| SQL 命名文法 | 1 位/4 位序号、重号、缺简述将被预检拦截 | 存量脚本重命名为三位定宽 `02-db-NNN-简述.sql` |
| 黑名单机制废除 | 曾靠 `$skipPatterns` 跳过的脚本将导致预检失败 | 备份类运维动作移出版本目录，登记人工操作（01 §5 / 04 §8） |
| 测试专用脚本 | 含 `@test-only` 或无校验区的脚本预检拦截 | 迁移至 `scripts/test-auto/` |
| 校验区强制 | 每个 02/03 脚本必须含尾部校验 SQL | 按 scripts-sql-规范 §4.1 模板补齐 |
| rta 执行阶段 | 原单阶段执行变为 quick→render 门控两阶段 | 旧脚本加 `-Stage` 支持或分拆两个脚本 |
