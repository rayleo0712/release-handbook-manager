### 8.4 05-1 优先级计数与回填命令

- 本节是 05-1 计数与回填命令的**唯一落点**；`05-1` 内只写「计数来源 = 04 §8.4」，不得内联命令本体
- 两条命令均在 `release/versions/{版本号}` 目录下执行：命令 1 = 统计各优先级用例总数，命令 2 = 回填 `05-1 §八 验收汇总表` 的「用例总数」列
- 验收启动前必须执行这两条命令完成计数回填，**不得人工数算手写**，避免统计错误
- 读写一律显式按 UTF-8 处理：禁止用 `Get-Content` 默认 ANSI 解码后再回写，否则文件中文将被永久破坏（编码口径见 `shell-编码与执行踩坑.md`）

**命令 1：统计 05-1 中各优先级用例总数**

```powershell
$p = (Resolve-Path "05-1-功能验收用例(非技术版).md").Path
$f = [System.IO.File]::ReadAllText($p, [System.Text.Encoding]::UTF8)
$p0 = ([regex]::Matches($f, '\|\s*[^|]+\|\s*[^|]+\|\s*[^|]+\|\s*P0\s*\|')).Count
$p1 = ([regex]::Matches($f, '\|\s*[^|]+\|\s*[^|]+\|\s*[^|]+\|\s*P1\s*\|')).Count
$p2 = ([regex]::Matches($f, '\|\s*[^|]+\|\s*[^|]+\|\s*P2\s*\|')).Count
Write-Host "P0=$p0  P1=$p1  P2=$p2  合计=$($p0+$p1+$p2)"
```

**命令 2：将统计结果自动回填 §八 汇总表「用例总数」列**

```powershell
$p = (Resolve-Path "05-1-功能验收用例(非技术版).md").Path
$c = [System.IO.File]::ReadAllText($p, [System.Text.Encoding]::UTF8)
$p0 = ([regex]::Matches($c, '\|\s*[^|]+\|\s*[^|]+\|\s*[^|]+\|\s*P0\s*\|')).Count
$p1 = ([regex]::Matches($c, '\|\s*[^|]+\|\s*[^|]+\|\s*[^|]+\|\s*P1\s*\|')).Count
$p2 = ([regex]::Matches($c, '\|\s*[^|]+\|\s*[^|]+\|\s*P2\s*\|')).Count
$sum = $p0 + $p1 + $p2
$c = $c.Replace('| P0（冒烟必过） | （留空，验收前回填） |', "| P0（冒烟必过） | $p0 |")
$c = $c.Replace('| P1（重要功能） | （留空，验收前回填） |', "| P1（重要功能） | $p1 |")
$c = $c.Replace('| P2（辅助/边界） | （留空，验收前回填） |', "| P2（辅助/边界） | $p2 |")
$c = $c.Replace('| **合计** | （留空，验收前回填） |', "| **合计** | $sum |")
[System.IO.File]::WriteAllText($p, $c, (New-Object System.Text.UTF8Encoding $false))
Write-Host "汇总表用例总数已回填完成"
```
